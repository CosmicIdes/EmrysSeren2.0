# EmrysSeren2.0

This project is a blog for the artist Emrys Seren. Patrons and fans can comment on Emrys Seren's blog posts. If time allows, I will also convert the rest of the original Emrys Seren website to Blazor/MudBlazor.

# Requirements

## Visual Appeal:
Design your project to be visually appealing; follow industry trends.
Make sure all text is spelled correctly and legibly.
Aim to create projects that employers find attractive and engaging.
Select a color palette and font stack to enhance design consistency
_Color palette:
*Purple/blue font
*Light lavender background
*Gold highlights

## Web-Based Application
Blazor/MudBlazor

## API - create your own
Create a blog with commenting enabled. Will be able to post blog entries, get blog entries, post comments, and get comments.

## Database Interaction

* Blog posts
* Blog post content
* Comments
* Timestamps
* Users
* Display Name

## Functions/Methods
Create and utilize a minimum of 3 functions or methods, with at least one returning a value integral to your application.
